# Resources

This folder is reserved for project resources such as:

- GitHub screenshots and social preview images
- example exported tilesets
- UI reference captures
- future preset files or documentation images

The generator itself does not require files in this folder to run.


## Preset reference

The application ships with the original six main color palettes (Meadow, Earth, Stone, Ocean, Sand, Frost) and nine texture presets (Smooth, Grainy, Rocky, Organic, Spikey, Cracked, Mossy, Chunky, Layered).

The optional tile grid is disabled by default and uses a 1 px #212121 overlay when enabled. The Spikey texture preset is tuned to be sharper and more aggressive, with smaller padding, stronger edge noise, and a pointier silhouette.


## Logo resource

- `resources/zense-logo.png` stores the Zense app/logo image used by the UI brand mark.




## v13 theme reference

- Dark theme background: `#212121`-based charcoal linear gradient.
- Pink theme background: `#FFC0CB`-based rose linear gradient.
- Light mode was removed; the app now switches between Dark and Pink only.
- Translucent surfaces and the animated background grid are UI-only resources.
